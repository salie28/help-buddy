# Help Me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A global "help me" key that screenshots the screen (or a preset area), asks Sonnet
about it through `claude -p`, and shows the answer in a frosted-glass Help window that
never takes focus.

**Architecture:** One single-instance Python GTK4/libadwaita app (`Gio.Application`
command line). It is built from pure-logic modules (config, history, markdown, the
command and parse half of the asker, crop math), which are unit-tested, and thin GTK/D-Bus
layers (portal capture, `Gio.Subprocess` runner, window, settings), which are verified by
running them.

**Tech Stack:** system `/usr/bin/python3`, PyGObject 3.56, GTK 4.22, libadwaita 1.9,
GdkPixbuf, xdg-desktop-portal 1.22 (Screenshot), Claude Code CLI 2.1.322, stdlib
`unittest`.

**Spec:** `docs/superpowers/specs/2026-11-10-helpme-design.md`

## Global Constraints

- No new packages: stdlib, PyGObject, GTK4, libadwaita, GdkPixbuf only. Tests use
  `unittest` (pytest is not installed).
- Shebang `#!/usr/bin/python3`, never `env python3` (a venv must not shadow `gi`).
- App id `local.claude.HelpMe`; command `helpme`; repo `~/helpme`.
- The window is never presented except: (a) first start by `helpme capture` when the app
  wasn't running, (b) `helpme` with no args (launcher/app grid), (c) the Settings/area
  picker the user opens.
- No timeout on claude. Retry: one automatic retry 20 s after a failure, then failed + log
  entry, never more.
- Claude command, exactly:
  `claude -p --model <model> --input-format stream-json --output-format stream-json --verbose --tools "" --no-session-persistence --strict-mcp-config --setting-sources "" --system-prompt <SYSTEM_PROMPT>`,
  run in cwd `$XDG_STATE_HOME/helpme/work` (empty dir). Never `--bare`.
- Do not call the portal's `org.freedesktop.host.portal.Registry.Register`.
- Glass: tint `rgba(37,37,37,.417)` → `rgba(13,13,13,.392)` (top → bottom), 1px edge
  `rgba(255,255,255,.09)`, radius 15px, white text.
- Defaults (Settings): capture_mode `"full"`, area `None`, shortcut `"<Super><Shift>h"`,
  prompt `"Look at this screenshot, work out what I'm doing and what I probably need help with, then help — short and practical."`,
  model `"sonnet"` (choices `sonnet`/`haiku`/`opus`), screenshot_dir
  `<GLib PICTURES dir>/Screenshots/HelpMe`, keep_days `30` (0 = keep), autostart `False`,
  jump_to_newest `True`.
- Paths honour XDG env vars: settings `$XDG_CONFIG_HOME/helpme/settings.json`, history
  `$XDG_DATA_HOME/helpme/history.json`, log `$XDG_STATE_HOME/helpme/helpme.log`.
- JSON files are written atomically (write `*.tmp`, then `os.replace`).
- Run all tests: `cd ~/helpme && python3 -m unittest discover -s tests -v`.

## Review Focus

1. **GNOME shortcut environment:** the custom shortcut runs without `~/.local/bin` on
   PATH. `helpme` must be bound by absolute path, and claude must be found via
   `shutil.which` with a `~/.local/bin/claude` fallback. Tested in Task 4
   (`test_find_claude_fallback`) and Task 7 (`test_shortcut_command_is_absolute`).
2. **Answer text that breaks Pango markup** (`<`, `&`, unclosed `**`, backticks inside
   code): it must render as text, never as a blank label. Task 3
   (`test_every_block_parses`).
3. **Busy-screen screenshots over the 5 MB per-image API limit:** the payload must be
   re-encoded or shrunk. Task 4 (`test_prepare_image_big_png_becomes_jpeg`).
4. **App quit while requests are running:** on next start those entries must show
   "Interrupted" with Retry, not spin forever. Task 2 (`test_load_marks_interrupted`).
5. **Corrupt or hand-edited settings/history JSON:** fall back to defaults per key and
   never crash. Task 1 (`test_corrupt_settings_gives_defaults`,
   `test_bad_value_falls_back_per_key`) and Task 2 (`test_corrupt_history_is_empty`).

### Task 4: Claude asker

**Files:**
- Create: `helpme/ask.py`, `tests/test_ask.py`

**Interfaces:**
- Consumes: `config.work_dir()`, `Settings.model`, `Settings.prompt`
- Produces:
  - Constants:
    - `SYSTEM_PROMPT = "The user pressed a 'help me' key and sent a screenshot of their screen. Help with what they are most likely stuck on. Be concise and practical. Use Markdown. Reply in the language of the user's prompt."`
    - `RETRY_DELAY_S = 20`
    - `MAX_ATTEMPTS = 2`
    - `MAX_IMAGE_BYTES = 3_500_000`
  - `find_claude() -> str | None`
  - `build_command(claude: str, model: str) -> list[str]` (exact flags from Global Constraints)
  - `prepare_image(path: str) -> tuple[bytes, str]`: returns `(data, media_type)`. The PNG bytes as-is if they are ≤ `MAX_IMAGE_BYTES`; otherwise a JPEG at quality 85, downscaled to a long edge of ≤ 1920, as `"image/jpeg"`.
  - `build_payload(data: bytes, media_type: str, prompt: str) -> bytes`: one stream-json line ending in `\n`. The shape is `{"type":"user","message":{"role":"user","content":[{"type":"image","source":{"type":"base64","media_type":…,"data":…}},{"type":"text","text":prompt}]}}`.
  - `@dataclass Result(ok: bool, text: str)`
  - `parse_output(stdout: str, stderr: str, exit_code: int) -> Result`. `ok` is true only if exit is 0, the last `{"type":"result"}` line has `is_error` false, and `result.strip()` is non-empty. On failure the text is the result text if any; otherwise the last non-empty stderr line; otherwise `f"claude exited with code {exit_code}"`. Lines that aren't JSON are ignored.
  - `retry_delay(attempt: int) -> int | None`: given the number of attempts made so far, 1 → `20`, ≥ 2 → `None`.
  - `class Asker`, which drives one request including the retry:
    - `ask(req_id: str, image: str, settings: Settings, on_retrying(req_id, error, delay), on_done(req_id, Result, attempts))`
    - `cancel(req_id) -> None`: force-exits the process or cancels the pending retry timer; then `on_done` is NOT called.
    - Attempts run through `Gio.Subprocess` with `STDIN_PIPE|STDOUT_PIPE|STDERR_PIPE`, `cwd=work_dir()` via `Gio.SubprocessLauncher.set_cwd`, and `communicate_async`.
    - Each failure is logged with `logging.getLogger("helpme")`: time, req_id, image, error. The final failure is logged at ERROR.
    - A missing claude binary counts as a failure with the text `"claude CLI not found (looked in PATH and ~/.local/bin)"`.

  - `test_build_command_exact`: `build_command("/x/claude", "sonnet")` equals the full flag list, with `"--tools", ""` as two items and `"--setting-sources", ""` as two items; `"--bare"` is not in it.
  - `test_payload_shape`: `json.loads(build_payload(b"\x89PNG", "image/png", "hi"))` has the image block first, the text `"hi"` second, and base64 that round-trips.
  - `test_parse_success`: stdout holding the system, assistant and result lines (`is_error` false, result "Blue") with exit 0 gives `Result(True, "Blue")`.
  - `test_parse_error_result`: the real error captured during planning, `{"type":"result","subtype":"success","is_error":true,"result":"There's an issue with the selected model (no-such-model)…"}` with exit 1, gives `ok False` with text starting "There's an issue".

  - `test_retry_delay`: `retry_delay(1) == 20`, `retry_delay(2) is None`.
  - `test_prepare_image_small_png_untouched`: a 64×64 PNG made with GdkPixbuf comes back with identical bytes and `"image/png"`.
  - `test_prepare_image_big_png_becomes_jpeg`: patch `MAX_IMAGE_BYTES` to 100 and use a 2560×1600 noise PNG. The result is `"image/jpeg"`, and its decoded long edge is ≤ 1920.
  - `test_find_claude_fallback`: with `PATH` set to an empty dir and a fake executable at `$HOME/.local/bin/claude` (HOME pointed to a temp dir), it returns that path; with neither present it returns `None`.

### Task 6: App + Help window

**Files:**
- Create: `helpme/app.py`, `helpme/window.py`, `helpme/style.css`

**Interfaces:**
- Consumes: Tasks 1–5 (`load_settings`, `History`, `render`, `Asker`, `Capturer`)
- Produces:
  - `app.main(argv) -> int`
  - `class HelpMeApp(Adw.Application)` (id `local.claude.HelpMe`, flags `HANDLES_COMMAND_LINE`)
  - `HelpWindow.show_request(req_id) / refresh(req_id) / show_library()`
  - app actions `app.capture`, `app.settings` (no-op stub until Task 7), `app.quit`

**Behaviour to implement:**

Command line:
- `helpme capture`: if no window exists yet, create it and `present()` it. Either way, start a capture.
- `helpme` (no args): create the window if needed, then `present()`.
- `helpme --background`: create nothing visible (used by autostart).

Lifetime and startup:
- `self.hold()` at startup, so a hidden window keeps the app alive.
- `close-request` → `set_visible(False)`, return True.
- On startup: `setup_logging()`, `History.load()`, `cleanup_screenshots(...)`, and load `style.css` via `Gtk.CssProvider` at APPLICATION priority.

Capture flow:
1. `Capturer.capture`.
2. On a path: `History.add` → `Asker.ask`.
3. `on_retrying`: status "retrying", error set, attempts.
4. `on_done`: status "done" with the answer, or "failed" with the error, plus attempts.
5. A capture error creates a failed request with no image, so the error is visible.

Every status change calls `window.refresh(id)`. A new request calls `window.show_request(id)` only if `jump_to_newest`; otherwise it only refreshes the library list. Nothing here calls `present()`.

Window layout:
- `Adw.ApplicationWindow` (default 460×720, CSS class `helpme`), holding an `Adw.NavigationView`.
- **Root page "Library":** an `Adw.HeaderBar` holding a Capture-now button (`camera-photo-symbolic`), a Settings button (`emblem-system-symbolic`) and a menu (Clear history, Quit). Below it, a `Gtk.ListBox` of rows with a 64 px-tall thumbnail, the first answer line or the status, the time, and a status dot class (`thinking`/`failed`/`done`).
- **Pushed page "Answer"** (back button = automatic NavigationView back), holding:
  - the screenshot (`Gtk.Picture`, max 260 px tall; click → `Gtk.FileLauncher` opens the image)
  - a time and mode line
  - a status row: spinner "Thinking…" / "Error — retrying in 20 s" / "Failed: <error>"
  - the answer blocks from `render()` (selectable labels; code in a `.code` box with monospace)
  - Copy (raw markdown to the clipboard), Delete (with `Adw.AlertDialog` confirm), Retry (failed/cancelled only; resets attempts and asks again) and Cancel × (thinking/retrying only)
- Initial view: the newest request on the Answer page if one exists. Otherwise an `Adw.StatusPage` "Press Super+Shift+H anywhere to get help" (showing the configured shortcut).

`style.css`:
- `window.helpme` background transparent
- the main box carries the glass gradient, edge and radius from Global Constraints
- labels white with `text-shadow 0 1px 2px rgba(0,0,0,.45)`
- `.code` at `rgba(0,0,0,.30)` with radius 8
- status dots: thinking `#f5c211`, failed `#e66100`, done `#2ec27e`
